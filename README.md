# EE108 — Computing for Engineers

Three Arduino projects from EE108, Maynooth University. Each was a
team assignment over roughly six weeks, covering circuit design in
Tinkercad, breadboard build, and C++ firmware.

| # | Project | Sensors & actuators | Presented |
|---|---------|---------------------|-----------|
| 01 | [Home Security Alarm](01-home-security-alarm/) | Ultrasonic, keypad, I²C LCD, buzzer | Oct 2024 |
| 02 | [Room Climate Monitor](02-room-climate-monitor/) | TMP36, potentiometers, LCD, RGB LEDs | Nov 2024 |
| 03 | [Smart Home Automation](03-smart-home-automation/) | PIR, ultrasonic, LDR, sound, servo, DC motor | Dec 2024 |

The three build on each other: 01 is a single sensor and one output,
02 adds analog conversion and a menu, 03 integrates five independent
subsystems on one processor — which turned out to be a scheduling
problem more than a wiring one.

Each project's README covers the design, what it does, and what I'd
change. My contribution is noted per project; teammates are credited
in the presentations.
